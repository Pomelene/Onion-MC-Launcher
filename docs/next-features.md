# 下一版功能实现与验证

本地开发预览，尚未发布。当前显示版本号保持 0.3.1 / 0.3.1-T，后续发布时再统一调整。没有加入启动器更新检查或使用人数上报。

## 模组检查与安装

实例管理 → 模组管理 → **检查并更新**。不提供额外模组检查或更新子页面。

- 本地读取 Fabric、Quilt、Forge / NeoForge 元数据，检查启用文件的 ID、必需依赖、可识别版本范围和声明的不兼容关系；支持 Fabric/Quilt 声明的内嵌 JAR 与别名。
- 读取有大小、数量及深度限制。未知版本表达式、条件依赖、未完整识别的组件仅提示待核对，不能当成完整的加载器求解器。Fabric 覆盖文件存在时，启动体检将相关依赖结论降为提示。
- 依赖问题由启动前体检报告；需要其他版本或前置时，在原有下载页面选择项目和版本。
- 更新用 **GET `/version_file/{sha1}?algorithm=sha1`** 识别本地文件；版本日期必须更新，默认仅选择正式版，测试版需要显式勾选。无法识别或查询失败的文件会说明未确认，不能据此宣称“全部最新”。
- 只在原模组列表保留 **检查并更新** 按钮。点击后使用已有任务进度窗进行扫描和更新，不再打开更新列表、依赖页面、方案页面或额外确认界面。未识别的文件只在完成状态中统计，不阻止其他项目更新。
- 新安装模组自动处理必需依赖。网络工作在后台进行；UI 不在工作线程中更新。更新现有模组只替换所选项目，不额外安装可选组件。

协议参考：[Fabric 元数据](https://docs.fabricmc.net/develop/loader/fabric-mod-json)、[Modrinth 版本 API](https://docs.modrinth.com/api/operations/getversion/)。独立实现，没有引入新的第三方运行时库。

## 旧文件保留

- 新文件先下载至游戏目录 `.onion/downloads/mod-updates/` 下的临时子目录，校验大小与 SHA-1 后，将原文件改名为 `原文件名.old`，再移入新文件；下载失败保留正在使用的原文件。
- 若同名 `.old` 已存在，使用 `.1.old` 等递增名称，避免覆盖已有文件。相同文件名的更新同样适用。
- 更新前及下载完成后重新核对所选原文件摘要、目标文件占用和游戏运行状态；目录切换、原文件变化或目标文件冲突时拒绝覆盖。发布失败时立即恢复原文件名。
- 不提供模组撤销或恢复操作页。旧文件保留在模组目录，不创建新的变更方案、恢复记录或备份目录。

## 环境与诊断

实例管理 → 管理 → **启动前环境体检**；运行日志中也提供入口。实际启动前执行本地检查。

检查运行目录边界和可写性、磁盘空间、实例占用、内存上下限、参数引号、显式指定的 Java 及已支持的依赖规则。未指定 Java 时保留原有自动选择/下载流程。非隔离实例可合法使用游戏根目录。

**崩溃诊断** 汇总最新崩溃报告、`logs/latest.log` 和 JVM `hs_err_pid` 日志，每份最多读取末尾 2 MiB。结果展示证据、来源和排查建议；普通提到 OptiFine/Shader 不作为崩溃证据，主类不可用也不再直接解释成缺少 Java。复制报告前隐藏常见令牌、密码及账户命令参数。规则匹配只提供线索，不保证根因。

## 实例与皮肤

- 实例列表侧栏 → **全部实例总览**，跨已保存文件夹扫描；支持名称、路径、标签搜索和仅收藏筛选，显示不可用目录。
- 选择由“规范目录 + 实例 ID”确定，切换目录扫描完成后再应用目标选择。收藏与标签同样按目录隔离，保存在现有 `onionmcl.json` 的实例分区；列表右键及实例管理可以修改。
- 收藏实例优先出现在当前列表、总览和首页快捷选择器中。
- 皮肤管理增加收藏和仅收藏筛选；收藏记录位于启动器 `.onion/skins/favorites.json`，以皮肤内容 SHA-256 标识，重命名后保留。筛选结果为空时清除预览并禁用应用/上传，避免误操作旧选择。

## 任务中心

下载 → **下载任务**，或下载进度条旁的入口。

- 覆盖主任务、游戏/内容安装、模组变更和 Java 下载。后台运行只隐藏进度窗口，不取消任务；回到任务中心会定位当前任务。
- 显示状态、阶段、文件进度、实际接收字节、目标目录和实例；支持取消。不会把历史接收字节当作实时速度。
- 安全任务在本次进程内保留显式重试配方；切换目录后拒绝在错误实例重放。账户认证等操作没有重放配方。重启后的历史只供查看，需要回到原页面重新操作。
- 最近 100 条历史保存在启动器 `.onion/tasks/history.json`，不保存可执行命令、账户或令牌。上次仍运行的任务标为已中断，不自动重放。

## 真实整合包回归修正

合并配置的游戏版本和 Java 要求从实际客户端 JAR 的 `version.json` 读取，并以文件路径、修改时间和大小为键缓存；实例展示名称不用于依赖判断。检查页明确显示 Minecraft、加载器和有效 Java 大版本，自动 Java 使用实际启动策略所需版本进行检查。

Fabric 描述文本兼容原始换行；服务端专用模组在客户端检查中忽略。内嵌依赖作为候选版本处理，按已选择模组的共同要求选取，不作为多个必载根模组直接报告重复。加载器 JAR 自带的组件（包括 MixinExtras）也纳入解析。嵌套字典上限调整为每个 32 MiB、总计 128 MiB，保持有界读取。`>=26.3-`、`~26.3-` 等空预发布标识及 Fabric 的 `^` / `~` 语义单独回归。

下载任务从工具坊迁至下载侧栏。实例列表与总览提供收藏、标签和搜索组合筛选；皮肤库提供名称搜索和仅收藏组合筛选。收藏按钮使用不同的空心 / 实心星形图像及可访问的勾选状态，不再只更改悬停提示。

## 检查性能

本地模组元数据采用最多 4 路并行读取，Modrinth 文件识别与更新查询采用最多 8 路并发（同时遵守下载并发数的较低值）。跨检查任务共享并发预算；只排入工作线程数量的任务，取消后停止排入新任务，并将取消事件传给网络工作线程。检查页显示已处理文件数，完成顺序不影响结果排序。

进程内缓存只保留模组元数据，以路径、加载器及文件身份、大小和纳秒时间戳检测变化；最多 512 个文件，估算元数据预算 16 MiB。修改、替换、启用或禁用模组后重新评估；Java、游戏版本等环境条件每次重新计算。缓存不写入磁盘。下载与替换时使用完整文件摘要，不用元数据缓存代替文件校验。
