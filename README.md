# Onion MC Launcher

[简体中文](README.md) | [English](README.en.md)

**免费、开源、公益开发的 Minecraft Java 版启动器。**

当前源码版本：[v0.3.2](https://github.com/Pomelene/Onion-MC-Launcher/tree/v0.3.1)。Windows 发布包见 [Releases](https://github.com/Pomelene/Onion-MC-Launcher/releases)，下载 ZIP 后解压运行 `OnionMinecraftLauncher.exe`。

**v0.3.2**：改进模组检查与直接更新、崩溃诊断和启动前体检；新增跨文件夹实例总览、收藏与标签、下载任务中心和皮肤收藏。统一列表布局，支持 Fabric / Quilt 原位更换；新建安装只生成一个实例，缓存统一收纳至 `.onion`。

**v0.3.1**：优化外观UI和使用体验

**v0.3.0.1**：首次启动按屏幕可用区域自动设置窗口大小；记住关闭时的窗口尺寸和最大化状态，换用较小屏幕时自动限制尺寸。窗口尺寸使用随 DPI 缩放的逻辑像素，与游戏分辨率设置独立。

v0.3.0.1 修复重发：移除误带入公众版的特供版网页初始化与社团导航，修复启动时缺少 `web_tools` 模块的崩溃；发布构建新增真实入口启动检查。

**v0.3.0 改进下载与整合包安装**：紧凑进度小窗显示真实任务阶段与网络速度；整合包在隐藏临时目录准备，成功后只生成一个独立实例；改进特殊字符待下载路径校验及头部底面皮肤贴图。

**v0.2.4 新增多游戏文件夹、工具坊与内容管理功能**：实例列表和首页快捷选择支持切换已保存的游戏目录，同名实例的设置与游玩记录隔离；Java 管理内嵌设置页面；新增原理图管理、连续截图列表、三维皮肤预览及上传、本地种子地图。启动器日志移至隐藏的 `.onion/logs`，配置格式升级前自动备份。

程序显示名称为 **Onion Minecraft Launcher**。项目使用 Python 和 PySide6 / Qt，致力于提供简洁的实例管理、游戏安装及内容管理体验，不以售卖启动器、账号或游戏资源为开发目的。欢迎学习、反馈和贡献。

## 功能概览

### 下一版开发（尚未发布）

- 原模组列表提供“检查并更新”，后台扫描并更新，下载校验成功再将旧文件改名为 `.old`；不增加检查或更新子页面。
- 启动前本地环境体检；结合游戏日志、崩溃报告和 JVM 错误日志的证据式诊断。
- 全部游戏文件夹的实例总览；实例收藏、标签及搜索；目录中的同名实例保持独立。
- 下载任务列表：实时状态、已接收数据、取消、后台运行及本次会话内安全任务重试；保留最近 100 条本地记录。
- 皮肤收藏、优先排序与仅收藏筛选；收藏随皮肤内容保存，重命名后保留。

依赖检查只覆盖可识别的元数据和版本范围，不代替加载器的完整解析。依赖搜索由用户选择项目和版本；新安装自动处理必需依赖。启动器自动更新检查未纳入本次开发。

- Qt 界面、实例选择、后台下载任务、取消及日志显示。
- 原版及 Fabric、Quilt、Forge、NeoForge、OptiFine 安装流程。
- 模组、资源包、光影、Modrinth / CurseForge 整合包管理。
- 存档备份、恢复及可恢复的文件移除机制。
- 账号管理、离线身份、外置认证及微软账号授权流程。
- 独立实例设置、Java 选择和启动参数管理。
- 保存多个游戏文件夹，在实例列表左侧或首页实例选择器中切换；各目录记住上次选择，同名实例的独立设置和游玩记录互相隔离。Java 管理已内嵌到设置页面，检测、选择及下载无需独立窗口。
- 设置自动保存、恢复上次选择的实例；主窗口与独立对话框统一使用随主题变化的自绘标题栏。
- 深色／浅色主题、特征色、粗体文字、独立文字透明度、窗口背景透明度，以及自定义首页背景与显示方式。

账号授权与发布者应用配置见 [微软登录说明](docs/microsoft-auth.md)。

## 从源码运行

v0.2.4 新增：实例原理图子目录管理、按时间倒序连续滚动的截图网格，以及工具坊中的皮肤库、三维预览、正版皮肤上传和本地种子地图。皮肤保存在 `.onion/skins/`；离线应用仅改变本地显示，正版上传会修改微软账户的 Minecraft 皮肤。种子地图采用 cubiomes 的 xpple 维护分支，支持列表中的 Java 原版版本至 26.3，包含新版生物群系和末地生成变化；不支持自定义世界生成规则。

当前主要开发环境：Windows、Python 3.13。

```powershell
git clone https://github.com/Pomelene/Onion-MC-Launcher.git
cd Onion-MC-Launcher
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

当前默认游戏目录为 `F:\.minecraft`，可在设置中修改为自己的游戏目录。设置、账户资料、实例名称和独立设置统一保存在程序同目录的 `onionmcl.json`，Windows 下自动设为隐藏文件；账号令牌继续使用 Windows 用户级加密。首次运行会迁移同目录旧 `config/` 中的四份配置，原文件保留。游戏、存档、Java 和日志仍独立存放。

后续构建的 EXE 输出到项目根目录 `release/`。只复制 EXE 到新目录且不携带 `onionmcl.json` 时，会使用默认配置；需要保留设置时应连同该隐藏文件一起备份。

Windows 账号令牌绑定原 Windows 用户，迁移到其他设备或用户后可能需要重新登录。请勿公开上传该配置文件。

启动器自身日志保存在同目录的 `.onion/logs/`，Windows 下自动隐藏 `.onion`。旧 `logs/` 中的启动器日志会安全归档到新目录；被占用的文件和其他内容保留。Minecraft 自身日志仍在各游戏运行目录中。

设置修改后会自动保存，无需点击保存按钮。实例默认跟随“设置 → 全局游戏设置”，下方以灰色展示继承值；勾选“仅为当前实例启用独立设置”后，修改只对该实例生效，不影响全局配置或其他实例。取消勾选会清除当前实例的覆盖项并恢复跟随全局。Java 检测与下载统一位于设置侧栏的“Java 管理”，游戏设置中的“Java 路径”用于指定所用运行时。

仓库不包含 Minecraft 游戏文件、Java 运行时、账号、访问令牌或开发者本机配置。游戏使用权与第三方内容许可需要用户自行合法取得；开源许可证不提供游戏授权。
