# Onion MC Launcher

[简体中文](README.md) | [English](README.en.md)

一个免费、开源、面向社区的 Minecraft Java 版启动器。

Onion 希望把游戏安装、实例管理和常用工具集中到一个简洁、可定制的界面中，让日常启动和管理游戏更方便。本项目以公益和交流学习为目的，不收取使用费用，不提供 Minecraft 游戏授权。

## 功能

### 账户与游戏启动

- 支持微软正版账户、离线账户和外置认证。
- 自动发现、选择和下载适用的 Java 运行环境。
- 支持内存分配、窗口尺寸、启动参数及游戏进程优先级设置。
- 支持全局游戏设置与实例独立设置，自动保存配置和上次选择。
- 提供启动前环境检查、运行日志和基础崩溃诊断。

### 游戏安装与实例管理

- 支持原版 Minecraft，以及 Fabric、Legacy Fabric、Forge、NeoForge、Quilt、OptiFine 的安装。
- 支持多个游戏文件夹和跨目录实例总览。
- 支持实例搜索、收藏、标签、重命名、复制和自定义图标。
- 支持在已有实例中更换 Fabric、Quilt 加载器版本。
- 支持导入 Modrinth、CurseForge 及常见 MultiMC／Prism 整合包。
- 支持导出 Modrinth 整合包，并选择需要包含的内容类别。

不同加载器和整合包格式的支持范围有所区别，复杂自定义组件不一定能够导入。

### 游戏内容管理

- 搜索和下载模组、资源包、光影，选择兼容的文件版本。
- 安装模组时处理必需依赖，检查并更新已安装模组。
- 管理模组启停，批量启用或停用搜索结果。
- 管理世界存档、备份、导出及存档中的数据包。
- 管理 Litematica 等原理图文件，支持子目录。
- 按时间浏览截图，支持多选、导出和移除。

### 工具坊

- 本地皮肤管理、收藏及可拖动旋转的三维预览。
- 正版账户皮肤上传、披风同步与选择。
- 本地种子地图，支持维度切换、坐标定位、缩放及结构标记。

### 外观与使用体验

- 深色、浅色和跟随系统模式。
- 自定义强调色，支持从背景图片提取主题色。
- 自定义背景图片、适配模式及覆盖范围。
- 分别调整 UI、文字和背景透明度。
- 调整字体、字号、粗体、圆角、模糊和动画时长。
- 支持自定义首页欢迎语。
- 提供下载进度、任务记录及启动器自动更新和历史版本选择。

## 版本选择

| 版本 | 适用场景 |
| --- | --- |
| 标准版 | 面向所有用户，提供通用启动与管理功能。 |
| THUnion 特供版 | 在标准版基础上增加清华联盟工坊的社团服务目录，版本号以 `-T` 结尾。 |

两个版本均公开发布。社团服务面向非官方、非营利组织清华联盟工坊的活动，不代表清华大学官方服务。

## 下载与使用

前往 [Releases](https://github.com/Pomelene/Onion-MC-Launcher/releases) 下载对应的 Windows x64 EXE，放在你希望保存启动器的目录中运行。

启动器设置保存在 EXE 同目录下的隐藏文件 `onionmcl.json`，日志、皮肤等辅助数据保存在隐藏目录 `.onion` 中。游戏文件保存在所选游戏目录，迁移启动器时请根据需要一并保留这些数据。

正版账户凭据使用 Windows 用户绑定的加密存储，换设备或更换 Windows 用户后可能需要重新登录。
