# 首页欢迎语与界面文案清理

首页默认不显示欢迎语，已删除随机选择逻辑和语料库。

“设置 → 外观 → 首页欢迎语”仅保留自定义开关、大字和小字。开启后显示用户输入；关闭时禁用输入、隐藏文字并保留原自定义内容。编辑立即预览，沿用设置自动保存与退出前刷新。空行隐藏；长句按可用宽度缩小，超长文字省略并通过悬停显示全文，始终保持每种字号一行。

配置键：`custom_home_welcome`（默认 false）、`home_welcome_large`、`home_welcome_small`，均在便携配置的 settings 分区。显示逻辑位于 `launcher/qtui/pages.py` 的 `update_home_welcome`，控件位于 `launcher/qtui/settings.py` 的“首页欢迎语”分组。

## 验证

`scripts/check_qt_welcome.py` 检查默认隐藏、立即预览、关闭时禁用输入、自定义内容保留、重启恢复、纯文本显示与深浅主题下的 1100/1440 窗口。使用临时游戏目录和临时配置，不操作真实游戏或账号。

## 首页启动按钮

`launcher/qtui/launch_control.py` 统一绘制两块点击区域的 16px 圆角外轮廓，整体尺寸 352 × 76；左侧 300px 启动区域、右侧 52px 快捷选择区域。标题与实例名共享左侧文字基线，采用 18px 半粗与 12px 常规字体；长实例名省略并保留完整悬停文字。启动使用线框火箭，空库安装使用加号，快捷选择使用细线箭头。禁用时保留同色底面，仅降低箭头强度。按下仅缩放内部内容，外框、接缝与点击区域保持固定。

验证还覆盖无真实启动行为的两块点击回调、禁用底色、接缝颜色与按下时的几何稳定性。
